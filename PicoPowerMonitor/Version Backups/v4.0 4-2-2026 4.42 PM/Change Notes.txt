I see something going on with this line
            _reconnectTimer.Tick += ReconnectTimer_Tick;

Cause
•	The EventHandler<T> delegate expects the sender parameter to be nullable (object? sender), but your handler is declared with a non-nullable object sender. That triggers CS8622.
Fix
•	Change the handler signature to accept a nullable sender:
Replace private void ReconnectTimer_Tick(object sender, object e) with private void ReconnectTimer_Tick(object? sender, object e)

Notes
•	Apply the same pattern to any other event handlers where the sender parameter is declared non-nullable but the event uses EventHandler/EventHandler<T>.
•	If you prefer project-wide behavior instead, adjust your nullable context (e.g., #nullable disable or project-level nullable settings), but the per-handler object? change is the minimal, correct fix.
