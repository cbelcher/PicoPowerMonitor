Asked Copilot
Is it possible to configure the UI window to be just the heigth and width needed to diplay the elements in it?

Response: Turns out this does not work in WinUI 3 only WPF.

Yes. Set the Window's SizeToContent so the window sizes itself to its children. Example changes to MainWindow.xaml:

<Window
    x:Class="PicoPowerMonitor.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:local="using:PicoPowerMonitor"
    xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
    xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
    mc:Ignorable="d"
    Title="Pico Power Monitor"
    SizeToContent="WidthAndHeight"
    WindowStartupLocation="CenterScreen"
    MinWidth="300"
    MinHeight="160">

Notes / gotchas
•	SizeToContent values: Width, Height, WidthAndHeight, or Manual.
•	If you want to prevent the user from resizing the window after it sizes to content, set ResizeMode="NoResize".
•	Use MinWidth/MinHeight to avoid the window becoming too small when content is minimal.
•	Dynamic content changes will automatically update the window size while SizeToContent is active.

Response:
You added WPF-only window attributes to a WinUI 3 window. WinUI 3 Window doesn't support SizeToContent or WindowStartupLocation (and some of the other attributes you added), which causes the XAML errors.
Quick fixes
•	Remove SizeToContent="WidthAndHeight" and WindowStartupLocation="CenterScreen" from MainWindow.xaml.
•	Set an explicit Width/Height in XAML (or compute them in code) and keep MinWidth/MinHeight only if they compile in your WinUI target.
If you want the window to size to its content at runtime, do it in code-behind. Example (MainWindow.xaml.cs):
`public MainWindow() { this.InitializeComponent();

// Measure content and resize window to fit
var root = (Microsoft.UI.Xaml.FrameworkElement)Content;
root.Measure(new Windows.Foundation.Size(double.PositiveInfinity, double.PositiveInfinity));
this.Width = root.DesiredSize.Width;
this.Height = root.DesiredSize.Height;

}`
If you also want to center the window, use the Windows AppWindow API (WinUI) after obtaining the window handle; that's more code but avoids unsupported XAML attributes.

        // Measure content and resize/center the window at runtime (WinUI 3)
        private void AdjustWindowToContent()
        {
            if (Content is FrameworkElement root)
            {
                // allow the content to measure itself unconstrained
                root.Measure(new Size(double.PositiveInfinity, double.PositiveInfinity));
                double desiredW = root.DesiredSize.Width;
                double desiredH = root.DesiredSize.Height;

                // enforce sensible minimums (previously in XAML)
                const double minW = 300;
                const double minH = 160;
                this.Width = Math.Max(desiredW, minW);
                this.Height = Math.Max(desiredH, minH);

                try
                {
                    // center using AppWindow APIs
                    var hwnd = WindowNative.GetWindowHandle(this);
                    var windowId = Win32Interop.GetWindowIdFromWindow(hwnd);
                    var appWindow = AppWindow.GetFromWindowId(windowId);

                    var displayArea = DisplayArea.GetFromWindowId(windowId, DisplayAreaFallback.Primary);
                    var work = displayArea.WorkArea;
                    int x = work.X + (work.Width - (int)this.Width) / 2;
                    int y = work.Y + (work.Height - (int)this.Height) / 2;

                    appWindow.Move(new Windows.Graphics.PointInt32(x, y));
                }
                catch
                {
                    // ignore if AppWindow APIs not available or call fails
                }
            }
        }
